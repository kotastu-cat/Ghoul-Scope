# SLOT SCOPE — L東京喰種 設定推測カウンター

## 内容
- `index.html`: アプリ本体（CSS/JavaScriptを内包。外部ライブラリ不要）
- `manifest.webmanifest`, `sw.js`, `icon.*`: HTTPS公開向けのPWA素材

## 使い方
1. `index.html` をブラウザで開くと試用できます。
2. 数字をタップして直接入力、`＋ / −` で1ずつカウントできます。通常時Gは±1・±10に対応。
3. 入力データはブラウザのローカルストレージに保存されます。ブラウザのデータ消去前に履歴・示唆タブからJSONバックアップを書き出してください。
4. 台を離れる前に「この台を履歴に保存」。履歴から読み込み・個別書き出し・削除ができます。
5. iPhoneでホーム画面追加・オフライン利用するには、ファイルを直接開くのではなくHTTPSのWebサイトとして公開してください。GitHub Pages等でこのフォルダのファイルを公開し、Safariの共有メニューから「ホーム画面に追加」を選びます。

## 解析値の扱い
設定別の数値は公開解析サイトの二次資料を参照しています。参照先・更新日の詳細はアプリ内の「解析比較」に記載。表示する相対整合度は簡易モデルによる参考スコアで、設定の実確率や設定確定を意味しません。通常・高確・超高確の状態を誤認した入力や、関連項目の相関によって結果が変わります。
